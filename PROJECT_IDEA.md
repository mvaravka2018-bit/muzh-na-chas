# PROJECT_IDEA.md — Муж на час: мультигородская платформа

## 1. Проблема

Рынок бытовых услуг в городах-миллионниках и региональных центрах (500k–1.5M жителей)
фрагментирован: мастера работают через личные рекомендации, Авито и WhatsApp-чаты.
Клиент тратит 40–90 минут на поиск, созвон и согласование мастера по одному звонку.
Мастер тратит 2–3 часа в день на самостоятельный маркетинг и теряет 30–40% потенциальных
заказов из-за отсутствия единого канала приёма заявок.
Существующие агрегаторы (YouDo, Profi.ru) берут 15–25% комиссии и не имеют локальной
идентичности, важной для доверия в регионах.

## 2. Решение

Telegram Mini App «Муж на час» — гиперлокальная платформа для мгновенного заказа
мастеров на бытовые и строительные задачи.

Пошаговый процесс:
1. Клиент открывает Mini App через Telegram-бот города → выбирает категорию услуги
2. Заполняет заявку: описание, адрес, удобное время, фото проблемы (опционально)
3. Система показывает доступных верифицированных мастеров с рейтингом и ценой
4. Клиент выбирает мастера и оплачивает онлайн (или наличными по факту)
5. Мастер получает уведомление, подтверждает заказ
6. После выполнения — клиент оставляет отзыв, платформа списывает комиссию 5%
7. Администратор города видит статистику и управляет мастерами через admin-панель

## 3. Почему сейчас

- Telegram Mini Apps достигли зрелости: 950M+ пользователей, встроенные платежи через Stars и ЮKassa
- В регионах России низкая конкуренция среди локальных платформ услуг
- После ухода Авито Pro для бизнеса ниша частично освободилась
- Мастера уже работают в Telegram-чатах — переход в Mini App органичен
- Архитектура мультигород закладывается с нуля: каждый новый город = настройка за 1 день без кода

## 4. Целевая аудитория

**Основная (клиенты):**
Жители городов 200k–2M человек, 28–55 лет, активные пользователи Telegram.
Задача: быстро найти проверенного мастера для бытовых задач (сантехника, электрика,
сборки мебели, мелкого ремонта) без долгих переговоров.
Текущий инструментарий: звонки знакомым, Авито, районные Telegram-чаты.

**Вторичная (мастера):**
Частные мастера и небольшие бригады, 25–50 лет.
Задача: стабильный поток заказов без затрат на рекламу.
Текущий инструментарий: сарафанное радио, личные страницы Авито, WhatsApp.

## 5. Архитектура системы

```
[Telegram Mini App] ← → [Next.js API / Edge Functions]
        ↓                          ↓
[Клиент: заявки,         [Supabase PostgreSQL]
 мастера, оплата]                  ↓
        ↓                [Supabase Auth + RLS]
[Мастер: заказы,                   ↓
 профиль, выплаты]       [ЮKassa / Telegram Stars]
        ↓                          ↓
[Admin панель]           [Telegram Bot API (уведомления)]
```

**Стек:**
- Frontend: Next.js 14 (App Router) + Tailwind CSS + shadcn/ui — скорость разработки
- Backend: Supabase (PostgreSQL + Auth + Realtime + Edge Functions) — масштабируемость без DevOps
- Платежи: ЮKassa (RU) — поддержка СБП, карт, эквайринг; Telegram Stars — нативно для Mini App
- Уведомления: Telegram Bot API — бесплатно, мгновенно
- Хостинг: Vercel (Next.js) + Supabase Cloud

**Ключевые модули:**
| Модуль | Вход | Выход |
|--------|------|-------|
| auth | telegram_id, city_id | session, user_role |
| catalog | city_id, category_slug | список услуг с ценами |
| order | user_id, service_id, address, datetime | order_id, assigned_master_id |
| payment | order_id, amount | payment_url, transaction_id |
| commission | order_id | списание 5% с баланса мастера |
| master_profile | master_id | рейтинг, отзывы, портфолио |
| city_admin | city_id | статистика, управление мастерами |
| notifications | event_type, user_id | Telegram-сообщение |

**Мультигород:**
Каждый город — запись в таблице `cities` с `slug`, `bot_token`, `timezone`, `commission_rate`.
Один экземпляр приложения обслуживает все города через `city_id` в каждой таблице.
Новый город: добавить запись в `cities` + настроить Telegram-бота за 30 минут.

## 6. Монетизация

| Уровень | Модель | Размер |
|---------|--------|--------|
| MVP | Комиссия 5% с каждого выполненного заказа | автоматически |
| v2 | Продвижение мастера в топ списка | 990 руб/мес |
| v2 | Верификация «Проверен» — разовый взнос | 500 руб |
| v3 | White-label города для партнёров | 15 000 руб/мес |

**Расчёт юнит-экономики (Тула, старт):**
- 20 заказов/день × средний чек 2 500 руб × 5% = 2 500 руб/день
- 30 дней = 75 000 руб/мес с одного города
- При 5 городах = 375 000 руб/мес без масштабирования команды

## 7. Конкуренты

| Конкурент | Что делает | Чего не хватает |
|-----------|-----------|----------------|
| YouDo | Агрегатор задач по всей РФ | Нет локальной идентичности, комиссия 15–25% |
| Profi.ru | Каталог специалистов | Нет Telegram Mini App, сложная регистрация |
| Авито Услуги | Доски объявлений | Нет онлайн-оплаты, нет верификации |
| ВКонтакте Mini Apps | Платформа | Нет готового решения для услуг |
| Локальные чаты | Telegram-группы | Нет структуры, нет оплаты, нет рейтингов |

**Наше преимущество:** нативный Telegram + верифицированные мастера + комиссия 5% (в 3× ниже рынка) + мультигород из коробки.

## 8. План запуска

**MVP (месяц 1–2) — Тула:**
- Цель: 10 активных мастеров, 50 заказов за месяц
- Метрики: конверсия заявка→заказ > 60%, средняя оценка мастера > 4.5
- Задачи: запуск Mini App, верификация первых мастеров, первые платежи через ЮKassa

**Фаза 2 (месяц 3–4) — 3 города:**
- Цель: Тула + 2 города-миллионника (Воронеж, Рязань)
- Метрики: 200 заказов/мес суммарно, 30+ мастеров на платформе
- Задачи: admin-панель для управления городами, реферальная программа для мастеров

**Фаза 3 (месяц 5–6) — масштаб:**
- Цель: 10 городов, партнёрская модель White-label
- Метрики: 1 000 заказов/мес, MRR 300 000+ руб
- Задачи: API для партнёров, аналитика по когортам, iOS/Android обёртка

## 9. Риски

| Риск | Вероятность | Митигация |
|------|-------------|-----------|
| Мало мастеров на старте | Высокая | Ручной рекрутинг первых 10 мастеров через Авито и ВКонтакте |
| Клиенты не доверяют новой платформе | Средняя | Верификация мастеров + гарантия возврата за первые 30 дней |
| ЮKassa отклоняет платежи | Низкая | Резервный вариант — оплата наличными с комиссией постфактум |
| Telegram изменит политику Mini Apps | Низкая | Параллельная веб-версия на том же Next.js |
| Мастер работает в обход платформы | Средняя | Комиссия 5% низкая, удобство платформы выше ручного учёта |

**Ключевые таблицы:**
```sql
cities(id uuid, slug text, name text, bot_token text, timezone text, commission_rate numeric DEFAULT 0.05)
users(id uuid, telegram_id bigint, city_id uuid FK, role text, phone text, created_at timestamptz)
masters(id uuid, user_id uuid FK, city_id uuid FK, is_verified bool, rating numeric, balance numeric)
categories(id uuid, city_id uuid FK, slug text, name text, base_price numeric)
orders(id uuid, client_id uuid FK, master_id uuid FK, city_id uuid FK, category_id uuid FK,
       address text, scheduled_at timestamptz, status text, total_amount numeric, commission_amount numeric)
payments(id uuid, order_id uuid FK, provider text, amount numeric, status text, provider_payment_id text)
reviews(id uuid, order_id uuid FK, rating int, comment text, created_at timestamptz)
```

**AI-пайплайн уведомлений:**
Edge Function `notify` принимает `{event: string, order_id: uuid}` →
читает данные заказа → формирует текст через шаблон → отправляет через Bot API нужному городу.
