# Skill: implement-feature

Используй этот навык каждый раз при реализации новой фичи или модуля.

## Шаги

1. **Прочитать спецификацию**
   Найти раздел модуля в `SPEC.md`. Прочитать полностью: user stories, модель данных, API, экраны, edge cases.

2. **Вызвать database-architect**
   Передать: модель данных из SPEC.md для этого модуля.
   Дождаться: созданных миграций в `supabase/migrations/`.

3. **Вызвать backend-engineer**
   Передать: API-эндпоинты и бизнес-логику из SPEC.md.
   Дождаться: реализованных routes в `src/app/api/`.

4. **Вызвать frontend-developer**
   Передать: список экранов и компонентов из SPEC.md.
   Дождаться: созданных страниц и компонентов.

5. **Вызвать qa-reviewer**
   Передать: список файлов, созданных в шагах 2-4.
   Дождаться: QA-отчёта.

6. **Исправить КРИТИЧНЫЕ и ВЫСОКИЕ проблемы**
   Вызвать нужного субагента для каждой группы проблем.

7. **Зафиксировать**
   Обновить `SPEC_TEMPLATE.md` если фича добавляет новые паттерны.

## Шаблон передачи задачи субагенту

```
Реализуй [название модуля] согласно спецификации в SPEC.md (раздел "Модуль N").

Файлы для создания:
- supabase/migrations/YYYYMMDD_NNN_name.sql
- src/app/api/[path]/route.ts
- src/components/app/[Component].tsx

Особые требования:
- [специфика из SPEC.md]
```
